## K8s The Hard way - Again!






There are a lot of versions of Kelsey Hightower's [K8s-the-hard-way](https://github.com/kelseyhightower/kubernetes-the-hard-way) are out there, So I decided to create one more 😜

This is a very good exercise to do if you want to learn K8s internal working. Although for production, I'd suggest some more automated and efficent method like [Kubeadm](https://kubernetes.io/docs/setup/production-environment/tools/kubeadm/create-cluster-kubeadm/), [Kubespray](https://github.com/kubernetes-sigs/kubespray) etc. or using a managed service like [EKS](https://aws.amazon.com/eks/), [GKE](https://cloud.google.com/kubernetes-engine) or [AKS](https://azure.microsoft.com/en-in/services/kubernetes-service/#overview).
